What's different about the alternative

  • Composition. Replaces the boat with a horizon line, a four-point gold north star above, and three bathymetric depth arcs below. Same harbor metaphor, less literal.
  • Type. Wordmark in Source Serif Pro Bold instead of bold sans — pairs with the site's existing serif headlines, reads more institutional.
  • Tagline lockup. Two small gold stars flank the tagline with a hairline gold rule separating it from the wordmark — same family as the current decoration, slightly more refined.
  • Bi-modal coloring. Navy elements use currentColor. Set color: cream on dark backgrounds, color: navy on light. One file works everywhere — no cream stamp pill required on the navy header.
  • Format. SVG instead of PNG. Crisp at every size including retina and print. ~2 KB file size. Themeable with CSS.

What stayed the same

  • Navy + muted gold palette.
  • Circular mark, with diagonal compass tick marks at the corners.
  • "REFUND / HARBOR" stacked in all caps, with the same overall horizontal lockup proportion as the current.
  • The tagline "TARIFF RECOVERY FOR U.S. IMPORTERS" with gold accent stars.
